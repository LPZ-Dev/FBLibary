## 📋 5 Automatic Formatting Rules {#converter-rules}

1. **Strain Name → UPPERCASE:** Every strain name outside the Genetics parentheses `( ... )` is converted to all caps (`BLOCKBERRY`).
2. **`pops` & `bigs` → Always Lowercase:** Words `pop` / `pops` in the strain name normalize to `pops`, and `big` / `bigs` normalize to `bigs` (always lowercase).
3. **Genetics `( ... )` → Case-Preserving:** Text inside `( ... )` keeps its original capitalization and wording (e.g., `(Black Cherry Punch x Tropicana Cookies)` or `(Big Bud x Lemon Pop)`).
4. **Strip Legacy Tags:** All bracketed tags `[Old Name: ...]`, `[...]` and `(old name: ...)` are removed automatically with clean spacing.
5. **Single-Line & Multi-Line Batch Input:** Paste multiple strains on separate lines or back-to-back on the same line (even glued to `)` or `]`) without garbled output.

## 📋 กฎการแปลงข้อความอัตโนมัติ 5 ข้อ {#converter-rules}

1. **ชื่อสายพันธุ์ → ตัวพิมพ์ใหญ่ทั้งหมด (UPPERCASE):** ชื่อสายพันธุ์ที่อยู่นอกวงเล็บ Genetics `( ... )` จะถูกแปลงเป็นตัวพิมพ์ใหญ่ทั้งหมด (เช่น `BLOCKBERRY`)
2. **`pops` และ `bigs` → ตัวพิมพ์เล็กเสมอ:** คำว่า `pop` / `pops` ในชื่อสายพันธุ์จะถูกแปลงเป็น `pops` และ `big` / `bigs` จะถูกแปลงเป็น `bigs` เสมอ
3. **ข้อมูล Genetics `( ... )` → คงตัวอักษรเดิม:** ข้อความในวงเล็บ `( ... )` จะคงตัวพิมพ์ใหญ่-เล็กและคำเดิมไว้ครบถ้วน (เช่น `(Black Cherry Punch x Tropicana Cookies)` หรือ `(Big Bud x Lemon Pop)`)
4. **ลบแท็กชื่อเก่าอัตโนมัติ:** ลบ `[Old Name: ...]`, แท็ก `[...]` ทุกชนิด และ `(old name: ...)` ออกพร้อมจัดช่องว่างให้อัตโนมัติ
5. **วางติดกันในบรรทัดเดียวก็ไม่เพี้ยน:** วางหลายสายพันธุ์ติดกันในบรรทัดเดียว (แม้ติดกับ `)` หรือ `]`) ระบบจะแยกแปลงทีละตัวให้ถูกต้อง 100%
